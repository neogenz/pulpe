# Pulpe

Pulpe est une application de budget gratuite qui aide à planifier les revenus, les dépenses et l’épargne sur une année. Elle montre ce qu’il restera chaque mois et comment une décision prise aujourd’hui modifie les mois suivants, sans demander de connexion bancaire.

## Préparer son budget annuel

Un budget Pulpe part d’un mois habituel, puis place les impôts, les vacances, les assurances et les gros achats dans les mois où ils auront réellement lieu. Cette vue annuelle aide à anticiper les écarts entre mois calmes et mois chargés au lieu de regarder uniquement les dépenses déjà passées.

## Projeter le disponible

Pulpe recalcule les mois suivants lorsque les revenus, les dépenses récurrentes, les dépenses ponctuelles ou l’épargne prévue changent. L’application permet aussi de répartir une dépense irrégulière sur plusieurs mois afin de voir combien mettre de côté et ce qui reste disponible.

## Utiliser Pulpe

Pulpe fonctionne en francs suisses et en euros, sur le web et sur iPhone. Le service est aujourd’hui gratuit, sans publicité ni abonnement, et son code source est public. Un mode démonstration permet de découvrir l’application sans compte et sans saisir ses propres chiffres.
