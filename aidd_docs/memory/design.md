# Design

## System
- Calm naturalism: warm neutral canvas, flat tonal hierarchy, and a top emotion zone over neutral content. `DESIGN.md` is cross-platform authority; platform `DESIGN.md` files extend it.
- Green means savings/actions, blue income/info, amber expense/warning, red only global-deficit hero or irreversible destruction.

## Tokens
- Angular: `frontend/projects/webapp/src/styles/`; iOS: `DesignTokens.swift`, `Color+Pulpe.swift`, `Typography.swift`; landing: `landing/app/globals.css`.

## Components
- Angular combines Material with `ui/`/`pattern/`; iOS uses shared SwiftUI atoms; landing owns small `components/ui` primitives.

## Accessibility
- WCAG AA, no color-only meaning, reduced-motion support, tabular amounts, Dynamic Type, and 44pt minimum iOS targets.
