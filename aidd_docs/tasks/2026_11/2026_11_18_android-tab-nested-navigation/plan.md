# Plan: Android per-tab nested navigation

Source: user report relayed by session local_622af059 — opening a month from the Budget tab shows the budget detail full screen and hides the bottom bar; iOS keeps the tabs.

Root cause: `android/src/app/(main)/_layout.tsx` is a `Stack` whose children are `(tabs)` and every detail route (`budget/[id]`, `budget/[id]/line/[lineId]`, `goal/[id]`, `goal/[id]/history`, `template/[id]`, `movements`, `to-point`, `settings/*`) as siblings. A push therefore covers the whole `Tabs` navigator, bar included. This is a deliberate choice since #669 (comment "A detail screen pushes over the bar"), which contradicts the product rule "same journeys as iOS". iOS gives each tab its own `NavigationStack` (`ios/Pulpe/App/MainTabView.swift`, `TemplatesTab.swift`, `NetWorthTab.swift`) and never hides the tab bar. Every detail screen listed above has the same defect, not only the budget.

## Rules

| Rule                                                                                                         | Why it applies                                                                     |
| ------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| Android has the same features and journeys as iOS, only look and interaction patterns are Android            | The bar staying visible and each tab keeping its history is a journey, not a look. |
| `.claude/rules/05-workflows-and-processes/posthog-events.md`: keep property value spaces stable once shipped | `tab_switched.tab` and screen names must keep today's values.                      |
| "A written rule beats the code next to it" (CLAUDE.md)                                                       | The #669 comment is precedent, not a rule; the parity rule wins.                   |

## Decisions

| Decision                                                                                                                                                                                                                                | Why                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Array group `(home,budgets,goals,templates)` for `budget/[id]`, its line, `goal/[id]`, its history; `template/[id]` in `(templates)` only; `movements`, `to-point`, `settings/*` in `(home)` only; `net-worth` stays a plain tab screen | Mirrors iOS: budget and goal pages registered in the accueil, budgets and objectifs stacks (`SectionStackDestinations`, `BudgetStackDestinations`); movements, to-point and account in the accueil stack only. Templates is added to the budget group because the Android template detail opens linked months (`template/[id].tsx:346`). URLs unchanged, so every in-tab `router.push("/budget/…")` keeps working and stays in the current tab. |
| Entries with no current tab (deep link) target `/(budgets)/budget/<id>`                                                                                                                                                                 | Matches iOS `openBudgetMonth` (switch to Budgets, push the month) instead of relying on alphabetical order.                                                                                                                                                                                                                                                                                                                                     |
| The tab shortcut `push("/goals")` from Accueil keeps switching tab                                                                                                                                                                      | `/goals` is a tab root, a Material bottom-nav destination; iOS pushes the list on the accueil stack, an accepted interaction-pattern difference.                                                                                                                                                                                                                                                                                                |
