# Codebase Audit: « Comparer avec mes comptes » (ui)

The three platforms build the same screens with the same states and hierarchy. Three issues need fixing: on iOS the « Oui, noter … » button cuts its amount at large text sizes, on Android the « Argent d'avant Pulpe » editor drops the minus sign, and on the web the struck-through old figure gives screen readers no context. The rest is minor accessibility, parity and token drift.

- **Date**: 2026_11_22
- **Scope**: `git diff origin/main` + uncommitted tree of `claude/reconciliation-onboarding-redo` (HEAD `5ed3423a2`, base `b3656f067`), UI only: `frontend/projects/webapp/src/app/pattern/reconcile-accounts/`, `ios/Pulpe/Features/CurrentMonth/Reconciliation/`, `android/src/features/current-month/components/reconcile-*`, checked against `DESIGN.md`, `frontend/DESIGN.md`, `ios/DESIGN.md`, `android/DESIGN.md`, `.claude/rules/` and `aidd_docs/tasks/2026_11/2026_11_20_comparer-avec-mes-comptes/spec.md`
- **Health**: good
- **Findings**: 0 critical, 3 major, 10 minor

Candidates checked and dropped:

- iOS « Voir les 1 autres » has a plural: `Localizable.xcstrings` carries `one`/`other` variations.
- « Réduire les animations » is honoured. Web: every scene animation has a `prefers-reduced-motion` override (`reconcile-guide-scenes.ts:101,302,496`). Android uses `useReducedMotion`, iOS uses `accessibilityReduceMotion`.
- Hidden amounts keep the step-2 sentences readable on all three platforms (web blurs the amount span only, iOS uses word variants, Android masks in its formatters). The web's remove buttons use `amounts-visible`, so they stay clickable.
- Hit areas: suggestion rows are at least 64 on all three platforms. The web segmented control is 44px. Icon buttons are 48dp/44pt. The text links use `expandedTapArea` or a 48dp `contentStyle`.
- The 35-word cap is exceeded on « Grand écart », « Tu as payé par carte… », the suggestions screen and « Je dois », and the gap amount is repeated in the question and the button. Both follow spec §4.4 word for word. The overruns are already logged by the owner (`decisions.md:221`: « 800 de plus » 50 words, « Écart 100 » 47 words), so this is a known trade-off, not a defect.
- « Salaire en avance » makes « Laisser comme ça » the filled action and the reasons the outlined one on all three platforms, with a stated reason in the code. Step 2 has no close button on any platform (back arrow only). Both are consistent and deliberate.

## Top actions

1. Let the iOS entry button wrap at accessibility sizes (row 1). It is a one-line change and the only place where the amount the user is about to write is cut off. Hand off to `aidd-dev:02-implement` or fix inline.
2. Replace `AmountField` in Android's starting-amount editor with a signed field (row 2), and add a spec that keeps « -500 » negative after an edit.
3. Give the web's struck-through figure a spoken « au lieu de » (row 3). It brings the web in line with iOS and Android, which already do this.
4. A small a11y batch: the iOS guide announcing each scene (row 4), the iOS starting-amount error text (row 5) and amount field names on web and Android (row 6).
5. A parity and token pass when convenient: state card, card help, chips, radii and motion, icon sizes, `.headline` (rows 8-13). `impeccable` can drive this pass.
