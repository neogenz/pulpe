## Homepage: proposed Android structure

Read-only audit, so this is the target, not a change. Everything below exists in `react-native-paper` already.

1. Top app bar (`Appbar.Header`, `surface`, elevates on scroll): month name left, account icon right.
2. Hero (keep the signature): mint tonal card, eyebrow + hero amount + trajectory with captions; tap opens the realized sheet.
3. "À pointer": the single tonal action card (`secondaryContainer`), one row, two buttons. Already the one-question model, just make it the only tinted block.
4. Écarts: `List.Subheader` + up to three `List.Item` rows on `background`, trailing amount, no wrapper.
5. Activité: `List.Subheader` + the existing `FilterChip` rail + `List.Item` rows grouped by day, "Tout voir" as a text button.
6. Bottom: Material 3 navigation bar via `BottomNavigation.Bar`; extended FAB "Ajouter" stays.
7. Forms: bottom-anchored `FormModal` first; full bottom sheet only if the `DESIGN.md` decision is reversed.

## beui / coss ui: verdict

No, for two independent reasons.

- Neither runs in React Native. beUI is React + Motion + Tailwind delivered through the shadcn registry; its catalog (`mcp__beui__list_components`: hover tilt, View Transition API theme toggle, Lenis scroll, SVG goo filters, `layoutId`) is DOM-only. coss ui is Cal.com's design system on Base UI + Tailwind, copy-paste, early development, DOM-only. Bringing either into Expo means `react-native-web` + NativeWind + a Motion port: a styling re-platform, not a component import.
- The problem is composition and idiom, not missing widgets. Every piece the proposal above needs ships in `react-native-paper` (`BottomNavigation.Bar`, `List.Item`, `List.Subheader`, `Card`, `Chip`, `Appbar`, `Dialog`). `android/DESIGN.md` says Material 3 is the kit and the signatures live in `src/ui`; a third visual language would break that split and the root `DESIGN.md` Two-Family Rule.

If a richer React Native kit is ever wanted, the native candidates are `react-native-reusables` (shadcn port on NativeWind) or `heroui-native`; both replace Paper's styling layer and are a separate decision.

Sources: [beUI](https://beui.dev/), [beUI on jQueryScript](https://next.jqueryscript.net/next-js/animated-components-blocks-beui/), [coss ui docs](https://coss.com/ui/docs), [cosscom/coss on GitHub](https://github.com/cosscom/coss), [coss ui on shadcn.io](https://www.shadcn.io/awesome/item/coss-ui).
