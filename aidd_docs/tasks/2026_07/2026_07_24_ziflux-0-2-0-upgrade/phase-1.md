### `2)` Replace the 14 hand-rolled DataCache mocks with one helper

> `cachedResource` now calls `_fetch` / `_settle`. Fix the shape once, in `core/testing/`, not fourteen times.

1. Add `createMockDataCache()` next to `createMockResourceRef` in `core/testing/test-utils.ts`. It returns the object literal the specs already share, with three corrections:
   - add `_fetch: (key, fn) => Promise.resolve(fn()).then(data => ({ data, record: { promise: Promise.resolve(), raced: false, superseded: false } }))`
   - add `_settle: (key, result, write = true) => { if (write) mock.set(key, result.data) }` so specs asserting on `set` keep working
   - drop `clearDirty`, removed from `DataCache` in 0.2.0
   Keep `version` and `_dataVersion` as `signal(0)`, and keep `deduplicate` / `prefetch` — `prefetch()` is still public API and `deduplicate` may still be reached by other code paths.
2. `_fetch` and `_settle` are `@internal` in ziflux and stripped from the published `.d.ts`, so the helper cannot type them against `DataCache`. Declare its own return type and cast at the injection site, exactly as the specs do today. Say so in one comment on the helper, so the next reader does not try to "fix" the missing type.
3. Replace each of the 14 files' inline literal with a `createMockDataCache()` call. Five files reach into the mock after construction (`mockCache.deduplicate.mockImplementation(...)` in `tag-store`, `savings-goals-store`, `budget-templates-store` ×2, and the shared `deduplicate` closure in `dashboard-store`); those overrides must move to `_fetch` and return the `{ data, record }` shape, not a bare value.
4. Delete the now-false `ngx-ziflux 0.0.13` comment headers the copies carry.
