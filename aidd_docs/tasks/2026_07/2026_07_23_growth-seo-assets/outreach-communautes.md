# Outreach communautés — answer first, deux créneaux sanctionnés

Ne rien poster tant que l’adoption « transaction » (mouvement réel) est sous 40 %. Ce kit prépare les textes. Il n’autorise pas l’envoi.

Les règles Reddit ont été lues via Wayback (Reddit bloque l’anonyme). Les revérifier connecté avant tout message.

## Créneaux sanctionnés

### r/Suisse (~54k, français)

- Règle 6 : pas de pub, sauf « intérêt public ». Contacter la modération **avant**.
- Message modos :

```
Bonjour,

Je développe Pulpe, une app de budget gratuite sans connexion bancaire. Je voudrais proposer un post sur un calculateur de budget suisse (primes, impôts, 3a), sans lien d’affiliation. Est-ce que ça passe la règle 6 (intérêt public) ?

https://pulpe.app/calculateur-budget

Maxime
```

- Post (seulement après accord) : centrer le calculateur et les chiffres OFSP/OFS, Pulpe en second.
